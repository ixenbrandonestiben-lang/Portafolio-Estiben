# Portafolio personal

Sitio web personal de **Brandon Estiben Ixén Teleguario**, creado para presentar su perfil, formación, habilidades y proyectos. El portafolio combina sus intereses en programación, tecnología y mecánica automotriz.

## Contenido

- **Inicio:** presentación y áreas de interés.
- **Sobre mí:** trayectoria, propósito y forma de trabajar.
- **Educación:** formación en programación y áreas técnicas.
- **Proyectos:** trabajos de programación e ideas en desarrollo.
- **Habilidades:** conocimientos técnicos y habilidades personales.
- **Fuera del código:** intereses y actividades personales.

## Tecnologías

- HTML5 para la estructura de las páginas.
- CSS3 para los estilos y el diseño adaptable.
- JavaScript para los controles de tema e idioma.

El sitio permite alternar entre tema claro y oscuro, y entre español e inglés. Las preferencias se guardan en el almacenamiento local del navegador.

## Cómo abrir el sitio

No se requiere instalar dependencias ni ejecutar un proceso de compilación. Clona o descarga el repositorio y abre `estructura/index.html` en un navegador.

También puedes usar la extensión **Live Server** de Visual Studio Code para servir el sitio localmente y recargarlo automáticamente al editar archivos.

## Estructura del proyecto

```text
.
├── css/          # Hojas de estilo de las páginas
├── estructura/   # Páginas HTML
├── img/          # Imágenes utilizadas por el portafolio
└── js/           # Funciones de tema e idioma
```

## Navegación

La página de inicio está en `estructura/index.html`. Las demás páginas HTML se encuentran en la misma carpeta y comparten los estilos y scripts ubicados en `css/` y `js/`.
